The Game of LEAP

Sailing Frog's LEAP is a distribution game on the XRP Ledger. Players start with 100 LEAP, distribute LEAP to other people, and earn points toward requesting another 200 LEAP distribution.

Project pages:
- index.html: game overview, rules, and player onboarding
- leaderboard.html: player leaderboard and progress toward the next distribution
- distributionMining.html: the distribution mining concept
- newToCryptos.html: getting started with an XRP Ledger wallet and LEAP

Site assets are in the images/ directory and in the PNG files at the project root. The js/ directory contains scripts for participant and score data. The .well-known/ directory contains XRP Ledger site and token information. CNAME configures the custom domain for GitHub Pages.

The site is a static HTML project. The leaderboard reads public XRP Ledger information; onboarding and distribution requests use the forms and services configured in the site pages.
